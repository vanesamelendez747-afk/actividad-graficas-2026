1. Difusión de calor

Campo de direcciones para el modelo de difusión de calor según la Ley de Enfriamiento de Newton. Se muestran diferentes soluciones para valores de C entre -2 y 2.

dT/dt = -k(T - Tamb)

Donde T representa la temperatura del cuerpo, Tamb la temperatura ambiente y k la constante de enfriamiento.

2. Flujo en tubería horizontal

Campo de direcciones para la velocidad de un fluido que circula por una tubería horizontal. Se representan diferentes condiciones iniciales.

dv/dx = -(f/2D)v|v|

Donde v es la velocidad, f es el coeficiente de fricción y D es el diámetro de la tubería.

3. Movimiento bajo fricción lineal

Campo de direcciones del movimiento de una partícula sometida a una fuerza constante y a una resistencia por fricción lineal.

dv/dt = -bv + F

Donde v es la velocidad, b es la constante de fricción y F es una fuerza constante.

4. Crecimiento poblacional logístico

Campo de direcciones del modelo de crecimiento poblacional logístico. Se muestran diferentes poblaciones iniciales entre 0 y 6 millones.

dN/dt = rN(1 - N/K)

Donde N es la población, r es la tasa de crecimiento y K es la capacidad máxima.
